# P&L Tracker

Simple daily P&L calendar for traders. Tap a day, enter your number, done.

## Features
- Daily P&L entry with tap-to-edit calendar
- Weekly totals on Saturday tiles
- Monthly P&L with W/L/Rate stats  
- Multiple account tracking
- 10 color themes
- Works offline
- Data saves locally on your device

## Setup
Hosted free on GitHub Pages. See SETUP.md for instructions.
